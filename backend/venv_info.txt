دليل البيئة الوهمية والاعتماديات (ARIA NEXUS Python Environment)
============================================================

تم استبعاد مجلد البيئة الوهمية (venv) من هذا الملف المضغوط لتقليل الحجم.
لإعادة إنشاء البيئة وتشغيل المشروع، يرجى اتباع الخطوات التالية:

1. إنشاء بيئة وهمية جديدة (Python 3.10 أو أحدث):
   python3 -m venv venv

2. تفعيل البيئة الوهمية:
   source venv/bin/activate

3. تثبيت الاعتماديات والمكتبات المطلوبة:
   pip install --upgrade pip
   pip install -r requirements.txt

4. تشغيل خادم النظام:
   ./run.bash

ملاحظة: تأكد من تحميل نماذج الذكاء الاصطناعي ووضعها في مجلد (models) قبل التشغيل.
